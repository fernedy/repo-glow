# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |

## Reporting a vulnerability

repo-glow is a local CLI with zero network calls — attacks surface is minimal, but if you find a vulnerability (e.g. command injection via crafted repo paths), report privately to **fernedy.arias@gmail.com**. Do not open a public issue for security bugs.

repo-glow never sends your code or metadata anywhere; the optional `--ai` mode invokes a local agent CLI on your own machine.
