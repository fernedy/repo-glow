# Changelog

All notable changes to repo-glow are documented here.

## [1.0.0] — 2026-09-13

### Added
- `audit` command: Glow Score 0–100 with 14 checks and actionable hints.
- `--share` flag: generates a shareable markdown badge block.
- `fix` command: creates LICENSE (MIT), .gitignore and CONTRIBUTING.md when missing.
- `fix --ai`: optional local agent integration (opencode) for repo description.
- Test suite (unittest, stdlib only) and CI on Python 3.8/3.10/3.12.
